# 20261112 Future Repository to CC Research Note prepresentation

Future work, excluded from the current demo: use JiuwenSwarm/AI4R to study reference repositories such as Strata, identify transferable engineering methods, distill them into Capability Capsules, apply them to a target such as llama.cpp and evaluate transfer.

The output should include the method and its applicability assumptions, source/licence provenance, integration guidance, optional reusable components/tools, and evidence obligations. Distinguish what the reference repository demonstrates from what has actually transferred to the target.

A first bounded example could extract one expert-read scheduling method, explain its hardware assumptions, adapt it to the target and compare against an unchanged baseline. A method that does not transfer is a valid finding. This is a proposal, not an implemented automatic CC-generation capability.
