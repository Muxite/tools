## Reconciliations made in this package

- The research project and agent are outside the pool; the pool contains available capabilities, not the whole research state.
- Capabilities are members; CCs are category packages. Verifiers/checks are bundled handles; lifecycle feedback is the circulation filter.
- Compatibility excludes unusable inputs before semantic ranking. Color is not a permanent type tag, and distance is task-relative relevance.
- Every initial category must become portable; a subset pilot cannot satisfy the milestone.
- The system is adaptive, but effect authority, scientific criteria and exact in-flight bindings are protected.
- Core behavior does not depend on today's diff against JiuwenSwarm; conversion mapping is a separate document.
- Existing VM/container lab decisions can host this architecture, but building more infrastructure is not a prerequisite for its first evidence-producing slice.
- M1/M1plus freezing and D20 review context are explicit proposed amendments. This package does not retroactively rewrite their authority or certify their past results.

The initial quality thresholds and two-attempt default are concrete design proposals chosen here to make implementation testable. They are not attributed to the user or presented as measured outcomes. Amend them before a trial if necessary; do not tune them after observing scores.
