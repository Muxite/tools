# Illustrative contract fixtures

[Agent entrypoint](../README.md) · [Schema guide](../schemas/README.md)

The valid examples describe a calculation member in a category capsule and a tiny research delivery. They exercise serialization and selected cross-record invariants. They do **not** supply executable workers, qualified checkers, real admission or a measured research result. Repeated synthetic digest characters are deliberate placeholders and must never be accepted as live qualification.

[Fixture index](fixtures.json) names expected schema/semantic outcomes. Invalid fixtures cover missing input contracts, skipped required checks, nonterminal acceptance, mismatched binding, and incomplete delivery. Runtime code needs the full fault suite from Level 2; passing these examples alone is not completion.

The quality-assessment fixture uses illustrative counts and dates only. Added negative cases reject mutable image tags and unsupported qualified trust from insufficient/stale evidence. Production policies must independently verify evidence, expiry and appropriate thresholds.
