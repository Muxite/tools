# Superagent and Strata — pinned source review

Read [[Designs/Inference Engine Software Factory - Design Impact]] for our proposed changes. This note records upstream observations, not implemented AI4R features. Both repositories were read at exact commits on November 2, 2026; no installers, agents, engines or upstream test suites were run.

## DeepSeek Superagent: a team-facing work controller

Pin: `6337fc823ce20251c8de8085948165c81aaa701e`. Local read-only reference checkout: [source](../../research/dsh-superagent-prototype-20261102). The [README](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/README.md) calls this a research prototype for one GitHub repository, tied to DeepSeek Harness; it explicitly distinguishes shipped code from future designs discussed elsewhere. We reviewed the shipped prototype, not an assumed full implementation of its associated article.

The [domain model](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/docs/001-domain.md), [authorization](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/docs/002-authorization.md) and [ports](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/core/ports.ts) separate incoming Triggers, conversation Threads, admission Decisions, scoped Tickets, Mandates and execution Assignments. That separation is useful: a new attempt does not have to invent a new authorized objective, and subscribed context need not grant permission. Policy versions accompany admission. Inferred work has off/observe/auto modes; explicit requests are separate. Observe mode records potential acceptance without dispatch. Resume revalidates the mandate, but policy changes do **not** immediately revoke every live ticket.

The [architecture](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/docs/007-architecture.md) identifies a transactional core, SQLite state, a persistent effects queue and external adapters. [Outbox code](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/app/outbox.ts) atomically records an outbound message and queues its send, then settles the receipt after the external call. This supports local deduplication; a crash after external success but before local settlement remains an uncertainty window unless the source adapter or external system reconciles it. It is not evidence of universal exactly-once external effects.

The [execution guide](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/docs/003-execution.md) preserves sessions/workspaces through retries and restarts. Recovery instructs workers to inspect existing external state before repeating actions. Blocked/failed tickets have a durable hold; ordinary bot traffic does not automatically wake them. Human-attention reporting distinguishes useful questions/results from routine progress. Relevant test sources include `tests/core-engine.spec.ts`, `tests/followups.spec.ts`, `tests/effects.spec.ts` and `tests/outbox.spec.ts`; their presence is not a passing test result in this review.

Important limits: command shims and per-ticket directories are explicitly defaults rather than a security boundary. Merge policy is partly prompt-governed and needs external branch protection for enforcement. The architecture documents unbounded historical record growth. Its request authorization does not establish scientific validity, independent checking, reproducible artifacts or CC qualification. The public package declares DeepSeek Harness `^0.2.1-alpha.2`; adopting its whole application would add a second agent runtime and platform integration burden. Prefer the domain patterns and narrow adapter concepts first.

## Strata: a concrete inference workload and backend candidate

Pin: `c62d5e3a15b40ea51c96aae9e8d36928965f53ab`. Local read-only reference checkout: [source](../../research/Strata-20261102). The [engine explanation](https://github.com/Niko1221/Strata/blob/c62d5e3a15b40ea51c96aae9e8d36928965f53ab/docs/HOW_IT_WORKS.md) describes hybrid memory/compute placement for supported mixture-of-experts models, adaptive expert caching, speculative generation and prompt reuse. These are model/backend-specific mechanisms, not a general claim that any model fits any hardware.

The [server implementation](https://github.com/Niko1221/Strata/blob/c62d5e3a15b40ea51c96aae9e8d36928965f53ab/serve/server.py) exposes OpenAI-style chat completions and Anthropic-style messages, streaming and cancellation plumbing. It also contains queue and batch-slot coordination. Relevant tests include `serve/test_server.py`, `serve/test_control_cancel.py`, `serve/test_quiet_cancel.py` and `serve/test_web_api_key.py`. API resemblance and test files do not establish JiuwenSwarm compatibility, cancellation completion, fairness or isolation on our machine.

The [DGX Spark guide](https://github.com/Niko1221/Strata/blob/c62d5e3a15b40ea51c96aae9e8d36928965f53ab/docs/DGX_SPARK_LINUX.md) is especially relevant to our GB10 plans: it reports an ARM64 CUDA path, specific supported packs and unsupported x86-dependent packs. Its cited environment is one Spark with Ubuntu 24.04, driver 580.173 and CUDA 13.0. It explicitly excludes a long soak and contexts above 128K from demonstrated coverage. Its Qwen configurations report only about 1–1.2 GiB of free memory at start. Treat those as upstream observations from a nearly full machine, not allocations available alongside our lab VMs. Picture reading was not tried there.

The same guide reports that fused prefill/FP4 settings can change logits and answers; its measured quality suite is bounded evidence. The model/quantization, expert count, prompt path and optimization flags therefore belong in result identity. A faster configuration cannot inherit the incumbent's correctness verdict. The [benchmark protocol](https://github.com/Niko1221/Strata/blob/c62d5e3a15b40ea51c96aae9e8d36928965f53ab/docs/BENCHMARK_PROTOCOL.md) separates default/custom tracks, cold/warm behavior, timing and task quality; it labels the standard protocol draft with pilot validation pending. Reuse this discipline, not headline token rates as our acceptance result.

The [safety inventory](https://github.com/Niko1221/Strata/blob/c62d5e3a15b40ea51c96aae9e8d36928965f53ab/docs/SAFETY.md) documents downloads, signed feeds, model hashes, remote image fetches and an automatic DeepSeek engine update check on launch. A research wrapper must resolve and lock actual artifacts and disable or contain update behavior during a frozen campaign. Local inference still needs network/effect policy; remote images and tools can cross boundaries. Source code is MIT, while model files and some bundled assets have separate licenses; admission must inventory the actual distribution.
