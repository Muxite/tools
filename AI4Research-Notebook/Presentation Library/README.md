# Presentation Library

**Actual files:** [[Presentation Library/Deck Catalog]] indexes decks and supporting material; [[Resources/Artifact Library]] covers the wider document collection. The sections below describe how to make and review presentations.

## Deck collection scope

Important presentations belong in this working library as actual files, including editable decks and useful exports, notes, and reproducible build sources where available. Existing archived originals count when indexed clearly. [[Designs/Working Library Maintenance Plan]] records the collection, provenance, and missing-file checks; this requirement is not a claim that every deck has already been collected. The guides below support the deck collection.

A reusable home for how you develop talks and research presentations. Start with the [quick guide](Presentation%20Guide.md), then use the [research argument and evidence guide](Research%20Narrative%20and%20Evidence.md) and [visual design guide](Visual%20Design%20and%20Whitespace.md). ## Main principle

Use the full canvas to communicate the argument: explain with diagrams, plots, tables, and carefully chosen text. Remove large unused areas that contribute nothing, while keeping clear margins and visual breathing room. When content cannot fit legibly, split the slide or move detail to speaker notes; do not solve it by shrinking text. Density is useful when hierarchy remains clear.
