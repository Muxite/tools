Requires **Docker running in Ubuntu/WSL**. From PowerShell: &#x20;
`wsl -d Ubuntu -u root`
&#x20; Then run in Ubuntu: &#x20;
`git clone --branch ai4r_M1 https://github.com/Stellven/jiuwenswarm.git cd jiuwenswarm  unset DOCKER_CONTEXT DOCKER_TLS_VERIFY DOCKER_CERT_PATH export DOCKER_HOST=unix:///var/run/docker.sock  docker build --platform linux/amd64 \   -f deploy/m1/Dockerfile.app --target production \   -t ai4r-m1-app:local .  mkdir -p /root/ai4r-web test -f /root/ai4r-web/config.yaml || printf '{}\n' > /root/ai4r-web/config.yaml chmod 644 /root/ai4r-web/config.yaml  export AI4R_APP_IMAGE=ai4r-m1-app:local export AI4R_OPERATOR_CONFIG=/root/ai4r-web/config.yaml export AI4R_JOB_ID=web-play  docker compose -p ai4r-web-play -f deploy/m1/compose.yaml up -d --no-build app docker compose -p ai4r-web-play -f deploy/m1/compose.yaml logs -f app`
&#x20; Open the **complete newest `Open JiuwenSwarm:` URL**, including `#research_bootstrap=...`. It works once.  This launches the **web inspection UI**. Research execution requires the configured operator resources and model account. &#x20;
