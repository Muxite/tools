# 2505.13400 · Robin: A Multi-Agent System for Automating Scientific Discovery

Ghareeb, Chang, Mitchener, Yiu, Szostkiewicz, Laurent, Razzak, White, Hinks, Rodriques · FutureHouse, Oxford · arXiv 19 May 2025 · 30 pp (11 body)
Read: body p1-11 in full

## Summary
A multi-agent system that joins **literature-based hypothesis generation** with
**experimental data analysis** in a lab-in-the-loop cycle, applied to therapeutics.
Given a disease name it proposes an in vitro assay and drug candidates; humans run the
experiments; Robin analyses the raw data and proposes the next round. Headline: it
proposed **ripasudil** (a ROCK inhibitor approved for glaucoma in Japan) for dry
age-related macular degeneration, and a follow-up RNA-seq pointed at ABCA1.

## How it works (p2-5, p8)
- **Crow** (concise) and **Falcon** (deep) literature agents, both PaperQA2-based;
  **Finch** data-analysis agent working in Jupyter via 2 tools (`edit_cell`,
  `submit_answer`) inside a fixed Docker image
- Pipeline: disease questions → 10 candidate mechanisms → assay reports → **LLM-judged
  pairwise tournament** (Bradley-Terry-Luce ranking) → 30 drug candidates → Falcon
  report per candidate → tournament → humans test top candidates → upload data →
  **10 parallel Finch trajectories + consensus meta-analysis** → new hypotheses
- Models: o4-mini generates; **Claude 3.7 Sonnet judges**. The judge prompt was
  generated by Gemini 2.5 Pro from expert pairwise preferences; judge top-10 matched
  experts' top-10 on 7.25 of 10 on average; judge self-consistency 88% vs humans 61% (p8)
- ⭐ "we observed that Robin almost always called tools in the same order, leading to
  a deterministic workflow. Therefore, we translated Robin into a streamlined Jupyter
  notebook to improve stability and ease of use" (p8)

## Results
- dAMD run: 151 papers → mechanisms; ~400 papers on RPE phagocytosis → 30 candidates;
  top 5 tested; Y-27632 (ROCK inhibitor) worked; second round of 10 drugs → ripasudil
  best (p5-6)
- RNA-seq: ABCA1 up 3-fold (adj. p = 2.13×10⁻⁸³); Finch trajectories agreed on the same
  genes in >50% of trajectories (p5-6)
- **Finch reported ripasudil raised phagocytosis 7.5-fold vs DMSO; the human analysis of
  the same data showed 1.75-fold** (p6-7, Supplementary Fig. S14)
- Hypotheses generated for 10 more diseases (supplement)

## Limitations (stated, p7)
- Produces experimental outlines, not executable protocols; humans translate and run
  them, and chose pHrodo beads instead of Robin's suggested substrate "due to
  availability" (p5)
- Finch "heavily reliant on prompt engineering by domain experts"
- Hypothesis ranking by LLM tournament; better alignment with human judgment needed
- Ripasudil vs Y-27632 needs dose and duration testing before a definitive comparison

## Relevance
- Verification is Tier III (wet lab) but the lab step is human-run and outside the
  agent loop; the survey (2608.05179) would code this as a terminal check, not an
  in-loop oracle
- ⭐ The 7.5× vs 1.75× gap is a measured example of an agent's analysis overstating an
  effect that a human re-analysis of the same data did not reproduce at that size
- ⭐ The move from agent to fixed notebook is independent evidence for AI4Research's
  premise: when the workflow is stable, compile it and stop letting a model choose the
  order each time (REPORT.md §3.2)
