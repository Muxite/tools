# 2601.08815 · Agent Contracts: A Formal Framework for Resource-Bounded Autonomous AI Systems

Ye, Tan · arXiv Jan 2026 · 22 pp (16 body)
Read: p1-7 (motivation, foundations, related work, contract definition); results from abstract

## Summary
Extends the Contract Net Protocol metaphor (1980) from **who** does a task to **within what
bounds** it may be done. An Agent Contract C = (I, O, S, R, T, Φ, Ψ) bundles input and
output specifications, the skill set, **multi-dimensional resource budgets**, temporal
limits, success criteria and termination conditions into one governance object with a
lifecycle. For multi-agent systems it adds **conservation laws**: budgets delegated to
sub-agents may never exceed the parent's.

## How it works (p2-7)
- Foundations: contract theory (moral hazard = unpredictable consumption; incomplete
  contracts = success criteria separate from strategy), normative MAS (budgets as
  prohibitions, success criteria as obligations), contract algorithms and real-time hard
  vs soft constraints (p2-3)
- Components: I = (schema, validation rules, preprocessing); O = (schema, **minimum quality
  Q_min**, format); S skills with costs; R token/API/time budgets; T deadlines; Φ measurable
  success conditions; Ψ termination events (p6-7)
- Violation of hard constraints triggers automatic termination; enforcement is structural
  because LLM agents are ephemeral and cannot be "sanctioned" (p3)
- Motivating incident: a multi-agent research system with no stop conditions looped for
  11 days and ran up a **$47,000** API bill (p1)
- Cites TALE's "token elasticity": LLMs exceed stated budgets, "prompting alone is
  insufficient for strict enforcement" (p4)
- Table 1 (p5-6): LangGraph, AutoGen, CrewAI, OpenAI Agents SDK, Google ADK, Bedrock,
  LlamaIndex, smolagents all have iteration limits and timeouts; **none** has cost
  budgets, deadlines, success criteria and delegation conservation as a formal contract

## Results (abstract)
- **90% token reduction** with **525× lower variance** in iterative workflows
- **Zero conservation violations** in multi-agent delegation
- Measurable quality-resource trade-offs across contract modes
