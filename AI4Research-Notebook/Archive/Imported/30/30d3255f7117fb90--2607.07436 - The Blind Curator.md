## Summary
Ratchet-style skill governance retires a skill when its observed contribution falls
below −τ, and promises the library cannot drift more than a margin below the no-skill
baseline. That promise assumes an **unbiased** pass/fail signal. With an LLM judge the
error is **asymmetric**. The paper separates **symmetric noise**, which only compresses the
retirement statistic, from **false-pass bias**, which shifts it up: past
**ρF→P = (1 − τ)/2 = 0.45 at τ = 0.10**, the modelled channel retires no skill at any
sample size (p2, p4, p13-14). Experiments inject corruption onto a **deterministic QC
grader's** training labels in real LLM skill-evolution loops. Genuine retirement goes to
about zero under bias in every subset, while the raw deprecation count and the eval score
often look normal: the curator fails **silently** (p6-8). A defect-injection audit
measures a judge's false-pass rate before deployment (p4-5, p9).

## How it works (p3-5, p12-14)
- **Loop** (Ratchet, unmodified): Critic labels failures, Synthesizer turns recurring
  failures into skills, Router injects **at most one skill per task**, Curator retires a
  skill whose contribution ĉ = 2p̂ − 1 ≤ −τ after ≥ Nmin trials, under cap C (p3-4, p13)
- **Testbed**: compose one report section from a frozen evidence slice; 155 slices from 5
  productions of an internal Chinese-language deep-research engine. Reward = 5
  deterministic QC checks (orphan citation, unregistered metric, unsourced number, broken
  cross-reference, missing TL;DR); PASS = zero violations; treated as ground truth (p3)
- **Channel model** (p4, p13): Pr[ỹ=1 | y=0] = ρF→P, Pr[ỹ=0 | y=1] = ρP→F. Observed pass
  rate → κp̄ + ρF→P, κ = 1 − ρF→P − ρP→F. Retirement fires when observed pass rate
  ≤ π_τ = (1 − τ)/2. Symmetric noise: effective threshold τ/(1−2ρ), Nmin ∝ (1−2ρ)⁻²,
  graceful for ρ < ½. Pure false-pass bias: fires only if
  p̄ ≤ (π_τ − ρF→P)/(1 − ρF→P), which is 0 at ρF→P = π_τ
- **Prop. 1′** (p14): bias-aware lower bound on expected eval pass@1; goes vacuous when
  ρF→P ≥ π_τ. Design rules: the lever against bias is τ, not Nmin; ρF→P is measurable
  offline
- **Runs** (Table 2, p12): 3 seeds × 12 rounds, τ = 0.10, Nmin = 24, C = 12. Channels:
  clean, noise ρ ∈ {0.1, 0.2, 0.3, 0.4}, false-pass bias **q ∈ {0.2, 0.45, 0.7}** (three
  points), and the audited LLM judge. Corruption on training labels only; eval always
  uses the true grader. Subsets: REPORT-MAIN-71, REPORT-BAND-58, REPORT-HARD-133 (Haiku
  4.5), MBPP+ HARD100 (Opus 4.7, unit tests), REPORT-WEAK-71 (3.5 Haiku)
- **Audit** (p4-5, p15): inject one known defect per class into clean sections (5
  QC-visible, 2 semantic: claim negation, number swap) and record whether a grader notices

## Results
- **Audit (Fig. 2, p4-5)**: QC recall 1.0 on visible classes, ~0 on semantic (claim
  negation 0.0, number swap 0.05). Held-out judge (Sonnet 4.6) flags number swap 98.5%,
  claim negation 92.7%, but its quality score barely moves on structural defects (p ≈ 0.5)
- **The in-loop judge is strict, not lenient**: ρF→P ≈ **0.01** (QC-visible, n = 210) and
  0.014 (semantic, n = 70), ρP→F ≈ **0.95** (n = 42), κ ≈ 0.04 (p5, p15). So the bias in the
  sweep is injected; the real judge sits in the "safe but starvation-prone" corner
- ⭐ **MAIN-71 (Table 1, p6)**, genuine retirements over 12 rounds: clean 1.3; noise
  0.7-1.0; **bias q = 0.2: 0.0, q = 0.45: 0.3, q = 0.7: 0.0**; LLM judge **10.3**. Raw
  deprecations stay 3.0-12.0 because cap-eviction fills in. Tail eval Δ vs clean: noise
  +0.018 to +0.060; bias −0.021 / **−0.065** / +0.039; judge +0.024. Harm is an
  **inverted U**, worst at q = 0.45 (p7)
- ⚠ Genuine retirement is **already 0.0 at q = 0.2**, well below the 0.45 cliff, and 0.3 at
  0.45. With only three bias points and a clean baseline of 1.3, the sweep does not locate
  a sharp threshold at 0.45; the paper says below the cliff "survival depends on skill
  margins" (p2)
- **BAND-58**: clean retires ≈ 7 per run, bias drives it to 0 by q = 0.45; raw deprecations
  9 / 5 / 1 at clean / 0.45 / 0.7 (p7, Fig. 6 p13)
- **Generality (p8)**: at q = 0.7 genuine retirement ≈ 0 in all subsets (MBPP+ 0.3,
  HARD-133 0.0). Eval harm only where synthesis starves: BAND-58 failures 20 → 6 per
  round, synthesis 20 → 11, eval −0.036; the abundant subsets keep ≈ 22 skills and hold
  their eval score
- **Non-divergence held**: all conditions within 0.125 of the no-skill floor (p7)
- **No lift**: clean evolution is 0.060 *below* the floor on MAIN-71 (p7). On BAND-58 a
  single-seed +0.12 shrank to +0.014 ± 0.054 over 3 seeds; paired re-measurement lift
  +0.26 violations, p = 0.63; clean vs bias-0.45 harm p = 0.61. Only the targeted class
  (unsourced numbers) improves, p = 0.03 on the full band (p7, Table 3 p16)

## Limitations
- Stated (p9, p17): one domain and composer, MBPP+ as a control; corruption is exogenous,
  so no real judge is shown past the cliff; a skill that *causes* judge blindness
  (adversarial coupling) is out of scope (p14); binary reward and single-skill
  attribution; audit transfer needs localisable defects; QC rewards citation discipline,
  not insight
- ⚠ Not stated: 3 seeds and 3 bias levels; the 0.45 figure is the theory's constant for
  τ = 0.10, not an empirically located transition
- ⚠ The false-pass rate is measured on **injected** defects in otherwise passing sections.
  Whether that matches the judge's rate on the failures a real loop produces is assumed
- ⚠ The 0.45 constant is Ratchet's rule; "a different governance rule inherits the same
  dichotomy with its own constant" (p17), stated, not tested

## Relevance
- **Supports**: any admission or retirement decision that thresholds a measured pass rate
  must know the grader's false-pass rate. Symmetric noise costs samples; one-sided
  leniency can switch the decision off entirely, and more trials do not help (p4, p14)
- **Supports**: deterministic checks and an LLM judge see disjoint defects (Fig. 2, p4-5),
  so a gate that uses only deterministic checks misses semantic defects
- **Supports**: auditing the grader once, before use, by defect injection against
  constructed ground truth (p5, p9, p17)
- **Does not address**: admission gates or append-only libraries. It studies
  *retirement* of prompt-snippet skills inside a running loop; its evidence that
  after-the-fact removal fails under a lenient judge is an argument about the removal
  signal, not a test of up-front admission
