# 2410.05080 · ScienceAgentBench: Toward Rigorous Assessment of Language Agents for Data-Driven Scientific Discovery

Chen et al. · Ohio State University and collaborators · ICLR 2025 · 60 pp (10 body)
Read: body p1-7 (motivation, construction, contamination strategy, evaluation, main results)

## Summary
Argues for assessing agents **task by task** before claiming end-to-end automation, and
explicitly positions itself against evaluating AI scientists with an LLM reviewer (cites
The AI Scientist). 102 tasks from **44 peer-reviewed papers** in bioinformatics,
computational chemistry, GIS, and psychology/cognitive neuroscience, each validated by
subject-matter experts; every task's output is a self-contained Python program (p2-5).

## How it works
- Each task: instruction, dataset info, optional **expert-provided knowledge**, and an
  annotated reference program adapted from the paper's released code (p3-4)
- **Task-specific success criteria implemented as executable scripts** (e.g. test ROC-AUC
  ≥ 0.77; top-5 repurposed drugs match gold; endpoints `math.isclose` to gold); figures
  judged by GPT-4o against the reference figure (Table 1, p5)
- ⭐ **Anti-shortcut and anti-contamination**: remove 5 random test points so memorised
  loaders produce misaligned results; for model tasks, re-split and replace test labels
  with dummy values, because agents (e.g. OpenHands) were caught **reading and reporting
  ground-truth test labels instead of training a model** (p4)
- Metrics: Valid Execution Rate, Success Rate, CodeBERTScore, API cost; plus rubric-based
  partial credit
- Quality control: 9 annotators + 9 experts; 41 instructions revised, tasks removed until
  102 remain

## Results
- Best agent with 3 attempts: **32.4%** solved independently, **34.3%** with expert
  knowledge; o1-preview with self-debug **42.2%** (p1-2)
- Claude-3.5-Sonnet with simple self-debug beats OpenHands CodeAct by 10.8 points at
  **17× lower cost** (p2)
- Conclusion: agents "cannot yet automate essential tasks in data-driven discovery nor
  the research pipelines end-to-end, in contrast to claims in recent work" (p3)

## Limitations
4 disciplines; Python-only outputs; figure quality relies on a GPT-4o judge.
