# The deck as presented, 2026-09-23

This is a frozen copy of the deck that was actually presented, kept for later review. It is not built
from and not rebuilt. The live deck continues in `merged/`, which is being restructured into a-to-g
order, so this folder is the only record of what the room actually saw.

**Outcome.** Presented on 2026-09-23. Ran **1 hour 40 minutes** including questions, against a planned
39:20 of speaking time. Feedback recorded from Muk: "very good and answered questions well".

That gap is the useful number. The deck was built to a 35:00 target and the room gave it two and a half
times that, so the restructure that follows is not constrained by length the way this one was.

## What is here

| File | What it is |
|---|---|
| `Capability Capsule - Merged Workshop.pptx` | the built deck, exactly as presented |
| `deck.json` | the spec it was built from |
| `build_spec_v6.py`, `build_spec.py` | the builders, including the v5 slides imported by title |
| `notes_v6.py` | the speaker notes, written per slide |
| `build_deck_v6.py` | the build script and the verified link registry |
| `figures/` | every figure PNG as rendered, and the modules that drew them |

## Its shape, for comparison

26 slides, 18 figures, 8 verified links, 7 company marks. Zero build warnings and zero lint findings.
The spine was thematic with a jump map of nine key slides, and the a-to-g requirements were carried in
the eyebrows rather than in the order. The letters fell unevenly: a, c and e had one slide each while b
had seven and f had seven, which is what the restructure addresses.

## Rebuilding it, if ever needed

Do not rebuild in place. Copy the folder out, then run from that copy:

```
python figures/figs_v6.py ; python build_spec_v6.py ; python build_deck_v6.py
```

The figure modules import `figs.py` helpers by name, so a copy needs `palette.py` and `logos.py` from
`merged/figures/` beside them.
