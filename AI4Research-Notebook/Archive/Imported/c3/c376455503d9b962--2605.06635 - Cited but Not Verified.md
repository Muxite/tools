# 2605.06635 · Cited but Not Verified: Parsing and Evaluating Source Attribution in LLM Deep Research Agents

Onweller, Lumer, Huber, Ramchandani, Subbiah, Feld · PricewaterhouseCoopers US ·
arXiv v1 7 May 2026 · 12 pp (9 body)
Read: full body p1-p9 plus tables.

## Summary
The clearest 2026 measurement of how good deep-research citations actually are.
A **Markdown AST parser extracts citation-claim pairs with no LLM inference at all**;
each pair is then scored on three increasingly hard dimensions — Link Works (HTTP
accessibility, no LLM), Relevant Content (LLM judge), Fact Check (LLM judge). 14 models,
130 queries from DeepResearch Bench and BrowseComp.

## How it works (p4-p6)
- ⭐ **Phase 1 is deterministic**: canonicalize → strip code blocks → build AST → extract
  citation nodes (`[1]`, `[^note]`, `[text](url)`, `<url>`, ranges `[1-3]`) → dedup
  registry → sentence-segment → **backward attribution** (a citation at the end of a
  passage applies to all preceding uncited sentences) (p5). The paper calls this
  "deterministic citation extraction" in its contributions list (p2)
- Phase 2 fetches each cited URL (JS-rendering extractor), then scores each
  attribution-citation pair in parallel (p5)
- Link Works = binary HTTP success. Relevant Content = LLM judge on claim vs first 5,000
  chars of source. Fact Check = LLM judge on facts/numbers/dates; **0 if contradicted,
  absent *or uncertain*** (p6) — a strict, unsupported-leaning rule
- Fact Check judge "calibrated through manual review of 50-100 LLM judgments" (p6)

## Results
- ⭐ **12 of 14 models exceed 94% Link Works and all frontier models exceed 80% Relevant
  Content, but Fact Check ranges 24%-77%** (p6-p7, Table 1). Best: Claude Opus 4.5
  76.8%; GPT-5.4 47.7%; GPT-5 Mini 38.9%; OSS-120B 24.4%
- ⭐ **Search depth ablation**: Fact Check drops ~42% on average from 2 → 150 tool calls;
  GPT-5.4 falls 78.6% → 16.7%, Claude Opus 4.6 80.0% → 57.9%, while Link Works and
  Relevant Content stay above 92% at every depth (p7-p8, Tables 2-3, p9)
- Sharpest single drop is 2 → 10 tool calls for GPT-5.4 (78.6% → 45.9%) (p8)
- Citation quantity trades against accuracy: GPT-5 Mini emits the most attributions
  (1,272) at 38.9% Fact Check (p7)
- Open-source task success 16.7%-40% vs 83%-100% frontier (p7)
- Link failures: GPT-5.4 1 bad link in 2,159; Llama 4 Maverick 19.2% (p8)

## Limitations
⚠ Both semantic dimensions are single-LLM-judge with no reported human agreement number —
only "calibration through manual review of 50-100 judgments" (p6); the authors themselves
name position and self-enhancement bias and suggest "hybrid approaches combining LLM
judges with rule-based verification" (p8).
⚠ Web citations are temporally unstable, so the numbers are not exactly reproducible (p8).
⚠ Fact Check scores 0 on *uncertain*, so the metric conflates "unsupported" with
"unjudgeable" and is a lower bound, not a truth rate.
⚠ Model versions (GPT-5.4, Claude Opus 4.6, Gemini 3.1 Pro) are one-shot proprietary
endpoints; no held-out split.

## Relevance
- ⭐ **Direct counterexample to "every reviewed claim system uses a model to extract"**:
  the extraction half here is a pure Markdown AST parser plus sentence segmentation plus a
  backward-attribution rule — structurally the same design as AI4Research's regex
  extractor, published at a venue-quality preprint in May 2026. The split is exactly
  AI4Research's: **deterministic provenance, model-judged truth**
- ⭐ Its headline result *is* the report's thesis with numbers: link validity and topical
  relevance (provenance-shaped signals) are near-saturated at 94%/80%, while the truth
  signal is 39-77%. Certifying "the sentence occurs in the cited section" would score in
  the 94% band and say nothing about the 39-77% band
- The depth ablation is the strongest 2026 evidence against "more retrieval fixes
  grounding": accuracy falls 42% as tool calls scale, i.e. generation capability scales
  and checking does not
- Best available 2026 number for **citation accuracy of deep-research agents**: 76.8%
  (Claude Opus 4.5), fleet average far lower (p7)
