## Summary
Open-ended, **cumulative** discovery over tabular datasets: six LLM agents run a
propose–test–accept loop whose accepted findings persist in a typed **insight graph**
that both stores results and steers later rounds. The distinctive engineering choice is
that hypothesis *testing* is not free-form code but a four-template statistical DSL
that compiles deterministically, so validity is a computed statistic rather than an
LLM opinion. Evaluated on Amazon Reviews, World Values Survey and SciSciNet against
"gold claims" mined from published papers on the same data.

## How it works (p3-4, p8)
- Insight graph G = (I, E): each node is (hypothesis, execution result, validity score
  s_v, novelty score s_n); edges typed {Deepens, Extends, Narrows, Contradicts}; the
  graph grows monotonically (p3-4)
- Round r: Orchestrator picks a mode ∈ {local, global, refine, conflict} and anchor
  insights; Historian assembles context; Generator proposes a batch of B = 10
  hypotheses; Critic filters structural/semantic duplicates and tautologies pre-execution;
  Coder/Runner executes; Evaluator computes s_v; Critic judges novelty and assigns
  Accept / Refine / Reject; Historian inserts accepted nodes and classifies edges
  (Alg. 1, p4). Stops after τ = 30 consecutive empty rounds
- ⭐ **Evaluator is mechanical** (p4, p6, Table 7): the current implementation "restricts
  execution to four templates in a statistical domain-specific language (assoc, diff,
  interact, heterogeneity) that compile deterministically", which "eliminates the
  estimator hallucinations and run-to-run drift of free-form code generation". s_v uses
  p_min = 0.05, an effect floor e_min = 0.03 and a **replication split** with penalties
  for split-sample instability
- Novelty s_n blends structural distance, embedding distance and an **LLM-assessed
  epistemic surprise** component (p4)
- Knowledge extraction (p4-5): embed query → seed nodes → one-hop expansion → LLM
  synthesis with node citations → separate judge LLM checks each claim by binary
  entailment, yielding Faith(q)
- Backbone: **Qwen 2.5-14B Q4_K_M on a single RTX 4090** (p6)

## Results
- Graph sizes (p7, Table 5): Amazon 119 insights / 268 relations; WVS 1,367 / 3,640;
  SciSciNet 565 (CS) and 1,027 (all fields)
- Open-ended quality (p6, Table 1): top-10 AutoKD insights vs 10 gold claims, 30 pairs,
  4 human + 4 LLM raters. AutoKD win rate (ties excluded), All raters, "Overall better":
  WVS 89.5%, Amazon 50.7%, SciSciNet 56.8%, **All 65.9%**. Human-only "Useful" 66.0%
  vs LLM-only 40.3%
- Conditioned quality (p7, Table 4): 15 literature-derived queries; 20.0% more-than-
  covered, 13.3% covered, 66.7% partially covered, 0% not covered
- Ablation on WVS, 1,000 rounds (p8, Table 6): w/o persistence → 16.7% exact
  rediscovery and deep-test share 28.9% → 12.5%; w/o graph structure → 26.0%;
  global-only → 20.1%

## Limitations
- ⭐ ⚠ **The headline preference rests on ratings with no inter-rater reliability.**
  Table 2 (p6) reports human Fleiss' κ of **0.112 overall** for "Overall better", and
  **negative** on WVS (−0.070) and SciSciNet (−0.053). LLM judges agree with each other
  (κ 0.728) but not with humans on Useful. A 65.9% win rate from four raters who do not
  agree with one another is not evidence of anything
- ⚠ The comparison set is the **top-10 of 1,367** WVS insights after score ranking and a
  diversity filter, Hungarian-matched to gold claims "to produce the most favorable
  pairing" (p5). Selection at both ends of the comparison
- The novelty gate and the extraction-time faithfulness check are LLM judges; the
  Faith(q) score is not reported in the body
- Statistical validity at p < 0.05 over a "combinatorially vast" hypothesis space (p6)
  with hundreds to thousands of accepted findings is a multiple-comparisons problem the
  paper does not address; the replication split mitigates but no false-discovery
  control is described
- 14B quantised backbone; results may not reflect what the design does with a frontier
  model. Template placeholder "Conference acronym 'XX, 2018" left in the header (p1)

## Relevance
- ⭐ **Partial counterexample to the report's claim that every claim-extraction system
  uses a model to extract and judge.** The *validity* verdict on each finding is a
  deterministic statistic from a fixed DSL, adopted precisely to remove LLM drift. The
  claim should be narrowed: model judgment remains for novelty, interest and
  faithfulness, but not for "does the data support this association"
- Its typed insight graph (Deepens / Extends / Narrows / **Contradicts**) is the only
  memory structure in this sweep that records disagreement between findings as a
  first-class edge — relevant to §3.3 and to any discussion of belief revision
- The Fleiss' κ table is a cautionary citation for §6: even 4-human panels on
  "interesting/surprising/useful" produce chance-level agreement, so LLM-judge
  validation against such panels is validating against noise
