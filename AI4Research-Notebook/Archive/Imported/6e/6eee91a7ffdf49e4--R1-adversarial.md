## Verdict

The draft has no fabricated citations. Every paper it cites exists in `papers/`, and most page references land on the right text. But 4 load-bearing claims are wrong in source, and they all lean the same way: toward AI4Research.

- **The DeepResearch Bench number is wrong.** The citation-accuracy range (77.96-94.04) is used 3 times, and it is also written into the register's "Numbers not to use" row as the corrected figure. It mixes 2 categories of system and drops the 2 lowest scores in Table 1, which are 39.36 and 48.67.
- **The claim-verification table misdescribes the code.** The literature-only `partially_supported` verdict is not "hash checked". It is a case-insensitive substring test. The SHA-256 check never affects any verdict, and no gate reads its result. That undercuts the report's "fabrication structurally detectable by hash" line and §6's first "ahead" bullet.
- **"Nobody writes experiment code at run time" is false as stated.** An enabled physical operator sends `$exp-run` and `$exp-design` to `codex exec`, and the AutoSci bridge writes a POC runner from a template.
- **"Every claim, method and report capsule is evidence_transform" is wrong.** Most report capsules declare no trust class at all.

The comparative framing overreaches in 4 places:
- It assigns verification-ladder tiers to systems, but the survey ranks sub-areas, not systems, and the report applies the ladder inconsistently: the AI Scientist and Agent Laboratory get no execution tier, while AI4Research and openJiuwen do.
- It reads ResearchClawBench as scored "rather than a model's opinion", when GPT-5.1 grades it.
- It treats CaMeL's whole 7-point utility drop as the price of fixing a plan.
- It claims AI4Research leads on the survey's central problem, external verification, which it has not done.

One omission is unfair to AI4Research: a clean 14/14 run with every node on attempt 1, earlier the same day, is not mentioned. The style rule passes: REPORT.md has no em dashes and no first person. The only "I" tokens are mermaid node ids.
