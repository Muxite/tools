## Build

| Output | Command, from `deck/` |
|---|---|
| diagrams | `python figures/figs.py` |
| paper figures for the appendix | `python figures/extract_paper_figs.py` |
| deck | `python build_spec.py`, `tundlekit deck lint deck.json`, `tundlekit deck build deck.json -o "Capability Capsule - Workshop 2026-09-22.pptx"` |
| report | `tundlekit report build companion.md -o "Capability Capsule - Schema Companion 2026-09-22.docx" --author "Muk Chunpongtong" --overwrite`, then `python docx_post.py <docx>` |
| check by eye | `tundlekit render office <file> -o <dir> --backend powerpoint` (Word and PowerPoint closed) |

Parity rule: every `##` heading in `companion.md` is a content-slide title in `deck.json`, in order.
`tundlekit text lint` flags the paper title *Don't Offer What Can't Be Done* as contractions; those are false positives.
