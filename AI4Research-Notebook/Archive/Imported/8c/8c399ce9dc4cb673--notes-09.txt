SAY: This paper asks what Alita-G never does: whether these tools work beyond the 1 task that made them. They kept every tool and tested it on hidden and adversarial inputs for its own job. Hand-written tools pass all of it, so a failure is the tool's fault. And 215 of 222 tools score zero. They run and return values, they give wrong answers on inputs they weren't built from, and a task only checks the input the tool was fitted to. Alita-G's 8 points came from tools built on the same GAIA questions it was scored on, the kind of input a fitted tool passes. Its paper also shows 1 tool reused on a different question, so the evidence goes both ways. The way to find out is to run Alita-G's library on questions it wasn't built from.
