# 2606.19819 · CREDENCE: Claim Reduction for Decomposition & Enhanced Credibility

Tran, Mai, Le · Vietnamese-German University, HCM University of Technology ·
arXiv v1 June 2026 (LREC journal submission, received April 2026) · 40 pp (37 body)
Read: abstract, method p6-p13, results p16-p26. Artifacts: SocialClaimSplit,
WikiSplitBench, ClaimDecompBench.

## Summary
The only 2026 paper that treats the **rule-based vs LLM** question about claim handling
as a formal one. It builds a decompose → **rule-based verify** → repair pipeline, proves
that the rule-based repair loop is monotone and terminates while LLM self-repair is
provably non-monotone, and measures how far a purely deterministic splitter gets.

## How it works
- **Verifier V is entirely rule-based** (p6): (1) atomicity by spaCy dependency parse
  (cc, advcl, relcl with subject-presence constraints); (2) entity preservation EPR by
  **Tier-1 regex** (dates, times, numbers, percentages, money) plus **Tier-2 spaCy NER**
  (PERSON/ORG/GPE/LOC), EPR = 1.0 enforced as a hard threshold (p9); (3) non-redundancy
  by BGE-large cosine ≥ τ_dup = 0.92
- Two repair tiers: `R_rule` (deterministic split + entity re-injection + dedup) and
  `R_LLM` (guided self-repair with the verifier report)
- **Theorem 1** (p11): rule repair never increases the compound-boundary violation count
  or redundancy and never decreases EPR. **Theorem 2** (p11): rule repair terminates in
  finitely many steps under an oracle-parser assumption. ⭐ **Theorem 3**: LLM self-repair
  is non-monotone with a constructible counterexample and needs an early-exit guard (p3)
- Default policy is **conditional gating**: if the rule verifier passes, the LLM is never
  called (p17-p18)
- Semantic-F1 = BGE-large cosine precision/recall, replacing Jaccard

## Results
- ⭐ **The deterministic checker measured against humans**: on 200 manually annotated
  outputs, the spaCy dependency atomicity checker reaches **precision 94.2%, recall 89.5%**
  vs human judgment (p24). False negatives 10.5%, false positives 5.8%
- ⭐ **The deterministic splitter measured alone**: SpaCy-senter (rule-based sentence
  splitter, no LLM) gets **EPR = 1.0 but AVR ≈ 0.52-0.56** and Semantic-F1 0.811 on every
  benchmark, vs 0.88-0.91 for the LLM decomposers (p22 Table 7, p23). The authors'
  conclusion: "rule-based splitting cannot resolve complex multi-clause structures" (p23)
- Rule repair cuts atomicity violations 58.6% for Phi-3-mini (0.138 → 0.057) and 54.0% for
  Qwen3-8B (0.087 → 0.040) with Semantic-F1 change < 0.001 (p17)
- ⭐ **LLM self-repair empirically regresses on ≈4% of SocialClaimSplit-100 examples**,
  dominant pattern being relative-clause reintroduction (p25-p26), confirming Theorem 3
- Verified local models beat an unverified frontier API: Qwen3-8B all-mode 0.903 vs
  Gemini Flash base 0.869 on WikiSplitBench-1000 (p20)
- Semantic-F1 beats Jaccard-F1 by +15.4 / +27.3 / +32.3 pp average per dataset (p24 Table 8)
- Redundancy flags manually audited: 71.6% true duplicates, 26.2% near-paraphrase,
  0.1% false positive (p26)

## Limitations
⚠ **SocialClaimSplit was built with the same conjunction-splitting logic as CREDENCE's own
rule repair** — the authors say so themselves (p14); conclusions from it are in-domain.
⚠ ClaimDecompBench references come from a rule-oracle, not humans, so its Semantic-F1 is a
lower bound only and "serves exclusively as a relative benchmark" (p15).
⚠ Human preference study is 82 pairs and underpowered: Semantic-F1 wins 45 vs 34 but
p = 0.2206 (p25).
⚠ Theorems 1-2 assume an ideal deterministic parser; the authors note spaCy is noisy (p11).
⚠ RR and Semantic-F1 share the BGE embedding (metric coupling); a MiniLM cross-check moves
RR by at most ±0.004 (p24).

## Relevance
- ⭐ **The single strongest hit against the report's "every reviewed claim system uses a
  model"**: a June-2026 paper whose verifier is regex + dependency parse + NER, with
  correctness theorems, and whose default policy skips the LLM entirely when the rules pass
- It also prices AI4Research's choice honestly. A deterministic extractor buys guaranteed
  termination, monotone improvement, EPR = 1.0 and a 94.2%/89.5% property checker; it costs
  roughly **-8 pp fidelity and a ~0.54 atomicity-violation rate** vs an LLM decomposer.
  AI4Research should quote SpaCy-senter's 0.811 / AVR 0.54 as the honest floor of a
  purely regex approach
- Theorem 3 plus the 4% empirical regression is a usable argument for AI4Research's frozen
  deterministic verdict table: an LLM asked to fix its own claims can make them worse, and
  there is no convergence guarantee
