# Windows setup

Installers for setting up a Windows machine. Layout and rules are in [../README.md](../README.md).

Most run by double-clicking. `.msi` files install silently with `msiexec /i <file> /qn`.

⚠ marks a stub installer that pulls the real package from the internet, so it won't work on an
offline machine. Replace those with offline installers when you get the chance.

The last three entries are files I couldn't identify. Rename them with the program and version, or
delete them if you don't recognise them either: an unidentified installer is a bad thing to carry
onto a new machine.
