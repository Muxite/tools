# 2505.18705 · AI-Researcher: Autonomous Scientific Innovation

Tang, Xia, Li, Huang · The University of Hong Kong (HKUDS) · arXiv 24 May 2025 · 38 pp
Read: p1-7 (system, benchmark, evaluation design), results tables (p9-12). Code: github.com/HKUDS/AI-Researcher

## Summary
An end-to-end multi-agent research system (literature → idea → implementation →
validation → manuscript) plus a benchmark, **Scientist-Bench**, that compares an
agent's output against a hidden human target paper. Its technical distinctive is a
**Resource Analyst** that decomposes an idea into "atomic concepts" and maps each
concept's mathematical formula to code in reference repositories, to reduce
hallucinated implementations.

## How it works (p5-7)
- **Knowledge Acquisition Agent**: from 10-15 user-supplied references, selects ≥5 GitHub
  repositories (recency, stars, README quality, relevance, citations) and fetches their
  arXiv LaTeX sources, all in Docker
- **Resource Analyst** (Paper Analyst + Code Analyst): concept decomposition → formula
  extraction from LaTeX via RAG → locate implementations in code → concept profiles with
  bidirectional formula↔code links
- **Plan Agent** → **Code Agent** with an **Advisor Agent** review loop (mentor-student
  refinement; supports test-time scaling)
- **Documentation Agent**: hierarchical writing (structure → detail → checklist revision)

## Scientist-Bench (p3-5, p9)
- 22 target papers (2022-2024, top-cited) across diffusion, vector quantisation, GNNs,
  recommenders; inputs are 15-20 references chosen by an LLM, an extracted research
  instruction, datasets; method names, details and citations anonymised
- Level 1 gives the instruction; Level 2 withholds it (open-ended)
- Evaluation: (1) an LLM **code review agent** gives a completion ratio; (2) an LLM
  **paper review agent** rates the AI paper against the target from −3 to +3, with
  order swapping and multiple LLM judges at temperature 1. Claimed validation: judges
  "perfectly align" with ICLR decisions on 32 paper pairs (p5)

## Results
- **93.8% completeness** with Claude-series models; failures from tensor-dimension and
  dtype errors (p10)
- Paper quality vs human targets (Table 2, p12): mean ratings are **negative** (e.g.
  −1.49 ± 1.49, −2.11 ± 1.21 in reported domains); "Comparable" is defined as a rating
  ≥ −1.0 and reaches 75.00% and 83.33% in those rows
- Reports better results on open-ended (Level 2) than guided (Level 1) tasks (p2)

## Critical notes
- Both stages are LLM judgments (Tier VIII); "completeness" is a code-review agent's
  opinion, not execution against held-out tests
- "Comparable" counts papers judged somewhat inferior as comparable; the mean says AI
  papers were rated worse than the human targets
- The verification-gap survey (2608.05179) lists AI-Researcher among end-to-end systems
  whose evaluation is largely LLM-based

## Relevance
- Resource Analyst's formula↔code mapping is the closest SoTA analogue to AI4Research's
  `code_evidence_map.v1` (claim/method → code location) and worth one line in §3.6
- Scientist-Bench's hidden-target-paper design is the same idea as ResearchClawBench
  (2606.07591), which scores against expert rubrics instead of an LLM paper judge
