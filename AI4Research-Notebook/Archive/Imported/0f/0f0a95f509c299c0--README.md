# code

Snapshots of the code behind the deliverables, for reading on any device. Each folder has a `SNAPSHOT.md`
saying where it came from, when, and at which git commit, and how to refresh it. Never edit a snapshot here:
change the source, then re-take it with `tundlekit bundle snapshot` and `release`.

| Folder | What it is |
|---|---|
| `tundlekit/` | the kit that builds the decks, checks the reports and keeps this tundle |
| `capsule-openjiuwen/` | the Capability Capsule knowledge base, schema, and report and deck builders |
