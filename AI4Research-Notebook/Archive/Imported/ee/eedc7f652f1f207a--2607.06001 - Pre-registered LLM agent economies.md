# 2607.06001 · Information Limits and Attractor Dynamics in Economies of Frontier LLM Agents: A Pre-Registered Test

Qian (self-funded) · arXiv Jul 2026 · 15 pp (11 body) · repo github.com/macrokit/value
Read: p1-11 (abstract, pre-registration chain and decision rule, protocol, results tables,
discussion, limitations, reproducibility) + Appendix A frozen band table (p12)

## Summary
Included here **for its methodology, not its physics**. It is the only paper in this sweep
that actually executes the freeze end to end: every prediction, acceptance band, protocol
gate and decision rule was committed to a public git repository **before the runs it
governs**, three amendments were each committed blind before the runs they modified, every
model call was cached so the whole analysis re-runs deterministically offline, and spend was
metered against a hard pre-committed cap. Total metered cost **$138.76** against a
pre-registered cap of $160 (p2, p5). The substantive content — information-theoretic
capacity limits and attractor dynamics in small markets of Claude Opus 4.8 agents — is
orthogonal to the report, but the discipline is the closest thing to AI4Research's frozen
contract that anyone has published.

## How the freeze works (p2-6)
- **Pre-registration chain**: a table of public commits each of which provably precedes the
  runs it governs — e.g. `a159ca9` capability-gate pre-registration → all gate runs;
  `4c0a7a1` full-grid pre-registration (P1-P6, bands, budget, decision rule) → all 2A/2B
  runs (p5)
- The **decision rule is applied mechanically by a committed analyzer**, not by the authors:
  "(1) PASS if P1-P3 and P5 pass..." (p5). Bands are numeric and stated in advance, e.g. P1
  worst pairwise deviation ≤ 0.05 nats; P2 all submodularity margins ≥ −0.03; P3 entropy
  slack 0.02 (Appendix A, p12)
- Anything outside a frozen band is typographically marked **Exploratory** throughout (p2)
- Cached determinism: a 19.9 MB per-call SQLite cache keyed by full request with per-call
  token metering is committed, so every individual model response is auditable and
  `analyze_stage2.py` "reproduces every number in this paper offline, deterministically, at
  zero cost" (p11)
- Gates that fire are disclosed rather than repaired silently: the first Experiment-A pass
  had genuine instrument faults (a 36% market parse rate) that the frozen gates caught (p6-7)

## Results (p2, p7-10)
- Prediction (i) confirmed within **all five** frozen primary bands: parimutuel gap law held
  to a worst-case **0.0457 nats against a band of 0.05**; submodularity worst margin −0.019
  against −0.03; the designed XOR control reached a supermodular gap of 0.621 ≥ 0.347, i.e.
  90% of the ideal ln 2 (p2, p7)
- Prediction (ii) returned the pre-registered verdict **CAP** ("cannot-answer-pass"): **0 of
  9** grid conditions were in-regime because goal dispersion collapsed in all **72** runs
  (max V = 4.85 against a frozen floor of 5.31, median 0.00) (p2, p8)
- P6 returned INCONCLUSIVE "by the rule's letter" because the floor definition never
  anticipated an empty regime — named as a **pre-registration drafting gap** rather than
  patched with a post-hoc floor (p9)
- P4b (clone equality) failed and is reported as it fell, with the mechanism explained and
  explicitly not re-litigated (p8)

## Limitations
- ⚠ **The commitment is a git commit ordering, not a cryptographic time-stamp.** The chain
  establishes that a commit precedes a run within a repository the author controls; there is
  no external anchoring (no OpenTimestamps, no transparency log) in what was run here (p5,
  p11). This matters for the report's claim: the freeze is enforced by *publication
  discipline*, not by an integrity hash the runtime itself must satisfy
- ⚠ Single vendor, single model family, one frontier tier — every verdict token from
  claude-opus-4-8 (p10)
- ⚠ Toy scale: N = 12-20 agents, T = 8-18 rounds, 8-state worlds, no market take, no
  bet-shading incentive, no entry/exit (p10)
- Elicitation is unincentivized — agents state posteriors and are not paid for calibration
  (p11)
- ~3 runs were double-sampled across a machine migration (cache-replayed, disclosed) (p11)
- Three amendments were committed after the original freeze; each is blind and pre-run, but
  a freeze that admits amendments is a weaker object than one that does not (p6, p11)

## Relevance
- REPORT.md §3.2 and the verification-gap argument (cross-reference 2608.05179, which
  *recommends* a pre-committed metric, split and threshold): this paper **does** it, and
  reports what it costs. Two of six predictions returned non-verdicts (CAP, INCONCLUSIVE)
  and one supporting prediction failed — that is the honest price of pre-commitment, and the
  report should cite it when arguing that a frozen evaluation criterion must be allowed to
  return "cannot answer"
- **Load-bearing question — the nearest precedent in spirit, and it confirms the claim.**
  The grading rules here are frozen before the run and applied mechanically by a committed
  analyzer, which is exactly the property the report says no reviewed *system* has. But the
  committer is a **human researcher**, the artefact is a markdown pre-registration in git,
  and nothing binds the criteria to the run's own integrity hash — an autonomous agent in
  this setup could not have sealed its own evaluator bindings, because there is no runtime
  object to seal them into. The claim survives; this is the human-methodology analogue the
  report should name as prior art and distinguish on autonomy
- The P6 drafting gap (p9) is a concrete failure mode for AI4Research's frozen contract: a
  pre-committed decision rule can be *well-formed and still undefined* on the outcome that
  actually occurs. The frozen contract needs an explicit undefined-branch policy
