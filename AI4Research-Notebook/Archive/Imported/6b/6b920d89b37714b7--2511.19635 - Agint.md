# 2511.19635 · Agint: Agentic Graph Compilation for Software Engineering Agents

Chivukula et al. · arXiv Nov 2025 · 18 pp (9 body)
Read: body p1-9 in full

## Summary
An "agentic graph compiler, interpreter, and runtime" that compiles natural-language
intent into **typed, effect-aware DAGs**, then progressively lowers each node from prose
to pure code. Heavy models lay out the graph ahead of time; small, fast models resolve
and run individual nodes. A systems paper with **no benchmark evaluation**.

## How it works (p2-5)
- ⚠ **6 type floors** in the body: TEXT → TYPED → SPEC (formal pre/post conditions) →
  STUB → SHIM (deterministic code calling AI "virtual functions") → PURE (no AI
  dependencies). The abstract gives a shortened 4-floor version (TEXT → TYPED → SPEC →
  CODE); cite the 6-floor version
- Intermediate representations are **executable**: a TYPED node runs by prompt chaining;
  a SHIM node mixes code with on-demand synthesis, so a partly specified workflow still runs
- Compiler mechanisms: type-directed resolution with explicit RESOLUTION_STATE;
  locality-preserving transformation (only neighbours matter, so subgraphs compile in
  parallel); fallback by decomposition, virtual functions, or deferred compilation
- **Runtime (Dagent)**: tracks side effects (filesystem, network, database) through an
  **effect monad**, enabling rollback and reproducible execution; modes Prefine, Dynamic
  (JIT synthesis), Predict (speculative execution)
- Toolchain: `dagify` (compiler), `dagent` (runtime), `schemagin`, `datagin`, all LLM calls
  through a single gateway (Flyte) with structured-output validation; can emit targets
  such as CrewAI, LangChain, WDL, BAML

## Limitations (stated, p8-9)
- Tested mainly on workflows with hundreds of nodes
- Primitive type system only (str, int, float, bool, lists)
- "comprehensive evaluation against established benchmarks remains future work"

## Relevance
- REPORT.md §3.1: the closest conceptual match to AI4Research's **compiled intent** in the
  coding-agent literature: NL → typed IR → specification with pre/postconditions →
  executable, with **effects tracked by the runtime**
- Difference: Agint keeps the graph editable and executes partially resolved nodes;
  AI4Research freezes the graph and hashes it before running. Agint's effect monad is
  runtime-enforced, which AI4Research's declared `effects` are not (see VARIANT-3 §36)
- Unevaluated: cite as design precedent only, never as evidence
