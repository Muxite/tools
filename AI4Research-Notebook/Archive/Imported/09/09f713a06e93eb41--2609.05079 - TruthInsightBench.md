# 2609.05079 · TruthInsightBench: An Evidence-Grounded Benchmark for Automated Evaluation of Open-Ended Scientific Discovery Agents

TruthInsight-AI (anonymous team) · arXiv v2 8 Sep 2026 · 27 pp (about 19 body)
Read: body p1-19 this session

## Summary
The only benchmark in this sweep that scores **how well a claim is evidenced** rather
than how close it is to a known answer. 40 blind tasks from 40 peer-reviewed papers;
the agent gets a neutral goal and frozen data, and a frozen LLM judge scores the
evidentiary maturity of the agent's *own* claims on 29 artifact-grounded items. The
headline finding is that four mainstream coding agents on one frozen model land in a
**statistically indistinguishable plateau**, strong on traceability and weak on exactly
the discriminating acts (controls, robustness, falsifiability, external validation).

## How it works (p6-10)
- Task τ = (g, D, M, T₀ | p*, F*, A*): goal, frozen data, metadata and a literature
  cutoff are visible; source study, two reference findings and all evaluation assets are
  hidden. T₀ is set strictly before the source paper's publication date (p6)
- 40 studies published 2018-2024 (34 Nature Communications, 2 Communications Physics,
  1 Nature Physics, 1 npj QI, 2 Science Advances) across 10 domains (p6, Table 2 p8).
  Admission requires interpretable structure, verified recoverability of ≥2 main
  results, and a testable space of repeats/controls. 8 construction-time verifications
  per task, 320 total (p7)
- Six scored dimensions summing to 100: evidence auditability 45, robustness 15,
  control testing 15, cross-dataset generalisation 10, novelty 10, falsifiability 5
  (Table 3, p9), decomposed into 29 items scored 0 / 0.5 / 1
- Task score = clamp(0.60·S1 + 0.20·S2 + B_yield + B_target − P_false, 0, 100), where
  S1/S2 are the two best semantically distinct claims, B_yield ≤10 rewards up to four
  claims that clear 40/100, B_target ≤10 compares against the two hidden reference
  findings *after* the run, and P_false deducts 5 per claim contradicted by the agent's
  own execution (p9-10)
- **Only executed analyses count**: "a test should be run" earns nothing (p9)

## Results
- Four agents on one frozen base model (DeepSeek-V4-Flash, thinking off; judge GLM-5.1
  W4A8, thinking off): Claude Code 60.27, OpenScience 59.03, Codex CLI 58.81, DeepSeek
  Harness 58.40 (Table 4, p12). Paired Wilcoxon finds **no pair separating at p<0.05**
  (smallest p = 0.118); TOST at ±4 points declares all six pairs equivalent (p12)
- Breadth without depth: 3.65-4.30 de-duplicated claims per task, but top-two evidence
  quality only 43.3-44.6 of 80, about 55% (Table 5, p13)
- Dimension profile (Table 6, p14): evidence auditability 78-81%, novelty 83-87%, but
  control testing 11-16%, robustness 9-14%, falsifiability 29-33%, cross-dataset
  generalisation **0.00-0.41%**. The strong/weak gap is 38-40 points (p14)
- Benchmark still discriminates: per-task scores span 36.2-72.9 and per-task spreads
  reach 25.5 points (p16); harder tasks show wider disagreement (Pearson r = −0.31,
  p = 0.049) (p16)

## Limitations (stated)
- **Protocol-level blindness only** — cannot rule out pretraining contamination (p18)
- Single frozen run per system-task; selection variance unmeasured (p18)
- One mid-capability base model; frontier models untested (p19)
- Single frozen, quantised, thinking-disabled LLM judge; no human calibration or
  second-judge audit yet (p19)
- Cross-dataset generalisation is partly floored by the benchmark (single-phase tasks),
  so its near-zero is not purely an agent failure (p14)

## Relevance
- **This is the benchmark AI4Research should run first.** Its scored object is
  verification quality — controls, robustness, falsifiability, deterministic-error
  penalty — which is exactly AI4Research's claimed strength, and the dimension where
  every existing agent scores under 16%. A system that forces controls and
  out-of-sample checks has ~45 points of headroom that no scaffold currently takes
- Scoring is automated and deterministic in aggregation, so it can be rerun each
  release without expert graders (p9, p18)
- ⚠ The plateau result is also a warning: on this instrument, **scaffold choice did not
  move the total score at all** under a fixed model. If AI4Research scores in the same
  58-60 band it has demonstrated nothing; the claim to make is dimension-level
  (control testing and robustness rates), not total score
- ⚠ B_target (≤10 pts) does reference the hidden source findings post-run, so the score
  is not purely endpoint-free; the authors report a main-body-only ablation preserving
  the ordering (p10)
