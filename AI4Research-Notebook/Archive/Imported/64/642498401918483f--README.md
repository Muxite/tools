## Provenance and trust

Claims are marked:

- **[verified]** — confirmed by running a command against the checkout.
- **[repo-claim]** — the repo's docs assert it; not independently tested.

This matters more here than in most repos: the project's documentation
explicitly warns that parts describe *aspirational* or *historical*
architecture rather than shipped behavior. **For a report, that distinction is
the difference between accurate and embarrassing.** See
[04-gotchas.md](04-gotchas.md) and the accuracy guardrails in
[09-report-presentation-kit.md](09-report-presentation-kit.md).

Nothing has been executed — no installer, no tests, no Solar runtime
(`~/.solar/` does not exist; Solar is not installed on this machine). All
runtime-behavior claims are therefore `[repo-claim]`.
