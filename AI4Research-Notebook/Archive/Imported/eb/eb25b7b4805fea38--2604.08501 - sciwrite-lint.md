# 2604.08501 · sciwrite-lint: Verification Infrastructure for the Age of Science Vibe-Writing

Samsonau · Authentic Research Partners, Princeton · arXiv v1 May 2026 · 20 pp (17 body)
Read: full body p1-p17. Code: github.com/authentic-research-partners/sciwrite-lint,
`pip install sciwrite-lint`.

## Summary
Citation and internal-consistency verification framed as **linting**: 23 checks run
locally on one consumer GPU, fast enough to re-run between revisions. Its explicit design
principle is "**deterministic checks where possible, LLM as semantic engine where language
understanding is required**" (p3) — an anti-agentic architecture.

## How it works (p5-p10)
- Six-stage pipeline: figure analysis + deterministic text checks → reference verification
  via APIs → download/parse (GROBID, 14 OA sources) → consistency checks on the *cited*
  papers → claim verification + bibliography verification of the cited papers' own
  references → aggregate reliability score
- ⭐ **Determinism boundary is stated explicitly** (p10): "Reference existence is checked
  via deterministic API lookups. Metadata accuracy uses fuzzy string matching with fixed
  thresholds. Retraction status is a database lookup. The LLM handles only tasks requiring
  language understanding… **The LLM never decides what to search, which tool to call, or
  how to plan**." Structured JSON in, structured JSON out
- Of the 23 checks (p8 Table 4), three are fully deterministic with no services
  (`dangling-cite`, `dangling-ref`, `unreferenced-figure`); reference existence /
  retraction / metadata are API + fixed-threshold matching; only claim support, purpose,
  consistency and figure checks use the LLM
- Reference reliability is a **fixed additive score table** (p7 Table 3): T1 0.9 / T2 0.7 /
  T3 0.3, retracted 0.0, −0.1 per metadata mismatch, −0.05 per consistency warning, etc.
- Matching engine for references without DOIs: product of title similarity, author overlap
  with name-variant expansion, quadratic year penalty, venue tiebreak; accept above 0.70 (p8)
- SciLint Score = internal consistency × weighted referencing quality × contribution,
  where citation purpose is weighted evidence 1.0 … context 0.2 (p5, p9)
- Deliberately pins open weights (Qwen3 8B FP8, Qwen3-VL, Arctic Embed): "a verification
  tool whose results change because the provider updated their API is not trustworthy" (p12)

## Results (p14)
- ⭐ **Error injection**: 68 synthetic errors into 30 unseen papers (13 arXiv, 17 bioRxiv).
  Detected 67/68 = **98.5% aggregate recall with zero false positives** —
  dangling-cite 38/38 (100%), dangling-ref 29/30 (96.7%). These are the *deterministic*
  checks
- ⚠ **False-positive adjudication**: 379 findings judged by Claude Sonnet — **14% true
  positive, 60% false positive, 26% uncertain** (p14). The FPs concentrate in the
  reference-DB checks on PDF papers lacking DOIs; "deterministic text checks have
  near-zero FPR" and DOI-present verification is "deterministic with zero FPR" (p14)
- Full pipeline completed on 27/30 papers, 1,755 findings (65/paper), SciLint 0.071-0.533
- Calibration: 30 of 38 ordinal constraints pass (79%) on 20 papers (p13)
- 8B vision model detects 100% of 62 injected figure errors; 2B detects 85% (p16)
- Cost: ~800 LLM calls and up to 30 min for a 50-reference paper; cached runs minutes (p7)

## Limitations
⚠ The 60% FPR is the headline negative and was measured *before* the matching engine
existed; the paper reports the fix but **does not re-report the FPR after it** (p14).
⚠ The false-positive adjudicator is itself an LLM (Claude Sonnet) judging a local-LLM
pipeline — judge circularity, and 26% of findings could not be resolved either way.
⚠ Calibration ordinal constraints are "our own assessment, not an independent benchmark"
(p13). The contribution/SciLint component is explicitly experimental and Qwen3-8B
"struggles with testability and specificity" (p16).
⚠ 30 papers, 20 calibration papers — small.

## Relevance
- ⭐ Second direct counterexample to "every reviewed claim system uses a model": a 2026
  tool whose whole selling point is a **structured pipeline over agentic architecture**,
  with reference existence, metadata, retraction and structural cross-references all
  decided by deterministic lookups and fixed thresholds
- ⭐ The **98.5% recall / zero FP on deterministic checks vs 60% FP on the model-mediated
  checks** is the cleanest published evidence for AI4Research's split: determinism is
  where the reliability is; the LLM is where the false positives are
- "The Verification Prior Hypothesis" (p11): smaller models may verify better than larger
  ones, because strong priors are exactly wrong when checking a paper that challenges
  consensus; cites MiniCheck (770M) at GPT-4 level. Argues against scaling the judge
- Context numbers worth quoting: 14.5% quotation-error rate in human-written papers across
  15 studies (p3); LLM reference hallucination 14-95% across 13 models (p3); 100 fabricated
  citations found in NeurIPS 2025 papers that passed 3-5 expert reviewers (p2);
  frontier models corrupt ~25% of document content over chained edit relays (p3)
- Its Table 1 (p4) is a ready-made competitor map: CiteAudit, CiteVerifier, RefChecker,
  SemanticCite, publisher screeners, scite.ai/GPTZero
