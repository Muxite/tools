# 2501.04227 · Agent Laboratory: Using LLM Agents as Research Assistants

Schmidgall, Su, Wang, Sun, Wu, Yu, Liu, Moor, Liu, Barsoum · AMD, Johns Hopkins, ETH Zurich · v2 17 Jun 2025 (cs.HC) · 84 pp (21 body)
Read: body p1-13 in full

## Summary
An LLM agent pipeline that takes a **human-provided research idea** and produces a code
repository and a research report. Deliberately positioned as an **assistant**, not an
autonomous scientist: it does not generate its own ideas, and it supports human feedback
at each stage ("co-pilot mode").

## How it works (p5-9)
3 phases with role agents (PhD, Postdoc, ML Engineer, SW Engineer, Professor):
1. **Literature review**: the PhD agent queries the arXiv API with `summary`, `full text`
   and `add paper` actions until N papers are curated
2. **Experimentation**:
   - plan formulation: PhD and Postdoc agents converge by dialogue; Postdoc submits a plan
   - data preparation: ML Engineer writes code, SW Engineer submits it; code must compile
   - running experiments with **`mle-solver`**: keeps a pool of top programs; EDIT (line
     range) or REPLACE (whole file); compile, up to 3 repair tries; **score 0-1 by an LLM
     reward model** judging adherence to the plan; self-reflection; batch-parallel
     modifications replace the worst program in the pool
   - results interpretation: PhD and Postdoc agree on an interpretation
3. **Report writing with `paper-solver`**: LaTeX scaffold of 8 sections, optional arXiv
   search, EDIT commands with LaTeX compilation check, scored by an adapted AI Scientist
   reviewer (65% accuracy vs 66% human on 500 ICLR 2022 papers, F1 0.57 vs 0.49, p9)

## Results
- o1-preview backend perceived most useful; o1-mini highest experimental quality; gpt-4o
  behind on all metrics (p2)
- ⭐ **Automated review overestimates quality: 6.1/10 vs 3.8/10 from human reviewers**
  overall, with similar gaps on clarity and contribution (p2)
- Co-pilot mode scored higher overall than autonomous mode, with trade-offs in
  experimental quality and usefulness (p2-3)
- Cost **$2.33 per paper** with gpt-4o; 84% cheaper than prior autonomous methods (p1, p3)
- `mle-solver` earns more medals (incl. gold and silver) on a subset of MLE-bench than
  MLAB, OpenHands and AIDE (p3)

## Limitations
- ML research only; idea supplied by a human
- Both the code scorer and the paper scorer are LLM judges (Tier VIII); the paper's own
  human study shows how far the paper scorer is from human judgment

## Relevance
