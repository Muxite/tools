# 2602.23452 · CiteAudit: You Cited It, But Did You Read It? A Benchmark for Verifying Scientific References in the LLM Era

Yuan, Shi, Zhang, Sun, Chawla, Ye · Notre Dame, Lehigh · arXiv v1 Feb 2026 · 13 pp (8 body)
Read: body p1-p8 including Tables 1, 3, 4.

## Summary
The first open benchmark for **hallucinated-citation detection**, with both a controlled
synthetic split and a naturally-occurring real-world split, plus an all-LLM multi-agent
verification pipeline. Its most useful result is unintended: the synthetic split and the
real split rank systems completely differently.

## How it works
- **Benchmark** (p3 Table 1): Generated test set 3,586 real / 2,500 fake, perturbed from
  verified BibTeX by a taxonomy (title keyword substitution, paraphrase, topic-conditioned
  fabrication; author addition/substitution; venue and year errors). Real-world test set
  **2,889 real / 467 naturally occurring hallucinated citations** harvested from OpenReview,
  Google Scholar, arXiv, bioRxiv and cross-checked field by field against authoritative
  records (p3)
- **Pipeline** (p6): Extractor (Qwen3-VL-235B, page-level OCR → JSON metadata schema) →
  Memory Agent (Mem0 knowledge graph, cosine 0.92 fast path) → Web Search Agent (Google
  API) → Scholar Agent (high-precision crawler) → Judge Agent (Gemini 3 Flash)
- ⭐ Despite being marketed as multi-agent, the **decision rule is a rule-based metadata
  consistency check**: the Judge executes a "Strict Consistency Criterion", and the final
  tier is "a second-pass **rule-based** metadata consistency check" (p6). Temperature 0.0
  throughout "to ensure deterministic and reproducible parsing and verification" (p6)

## Results
- ⭐ **Base rate of naturally occurring hallucinated citations in the real-world split:
  467 of 3,356 = 13.9%** (p3 Table 1, p7)
- Generated test set (p6 Table 3): GPT-5.2 Acc 0.965 / Prec 1.000 / Rec 0.914 / F1 0.955;
  CiteAudit Acc 0.966 / F1 0.959; GPTZero F1 0.734; Claude-Sonnet-4.5 F1 0.594 (recall
  0.990 but 3,364 false positives)
- ⭐ **Real-world test set (p7 Table 4) collapses**: GPT-5.2 F1 **0.955 → 0.331**
  (precision 0.210); GPTZero 0.734 → 0.313; Gemini-3-Pro 0.769 → 0.571;
  Mixtral 0.655 → 0.144. CiteAudit 0.959 → 0.838
- CiteAudit beats second-best on the real set by 0.267 F1 absolute (p7)
- Cost/latency: 11.2 s per 10 refs at $0.50/$3.00 per 1M tokens, vs GPT-5.2 at 48.8 s (p6-p7)

## Limitations
⚠ **Self-reported, and the authors' own system is the only one tuned on this data**; every
baseline is an off-the-shelf model or a commercial detector prompted for the task, not a
system designed for it. The 0.267 margin is between a purpose-built pipeline and
general-purpose baselines.
⚠ The real-world "gold" labels come from the authors' own manual cross-checking, which they
concede is "highly labor-intensive and difficult to scale" (p3); no inter-annotator
agreement is reported anywhere.
⚠ Scope is **existence and metadata consistency only** — it never checks whether the cited
paper supports the claim. A citation that exists and is correctly formatted passes.
⚠ Extraction runs on a B200 cluster with a 235B VLM; not reproducible cheaply.
⚠ sciwrite-lint (2604.08501, p15) reports that as of May 2026 neither the benchmark nor the
pipeline code had been released.

## Relevance
- ⭐ **The generated-vs-real collapse is the best adversarial ammunition in this slice**:
  F1 0.955 on synthetic perturbations, 0.331 on real citation errors, same model, same
  task. Any claim-verification number measured on injected errors — including
  sciwrite-lint's 98.5% injection recall and DeepFact's adversarial micro-golds — should be
  read with this in mind, and so should any AI4Research evaluation built on synthetic
  perturbation
- **13.9% natural hallucinated-citation rate** is the 2026 base rate for fabricated or
  metadata-wrong references in real manuscripts; compare urlhealth's 3-13% URL figure
  (2604.03173) and Xu et al.'s 14-95% model-generation figure quoted in sciwrite-lint (p3)
- Another partly-deterministic verdict: the final arbiter is a fixed consistency criterion
  applied to retrieved canonical metadata, with the LLM doing extraction and routing. This
  is AI4Research's split again — models find evidence, a rule decides
- ⚠ Shows the ceiling of the provenance-only approach: CiteAudit certifies that a reference
  exists and its fields match. It says nothing about whether the sentence citing it is true
