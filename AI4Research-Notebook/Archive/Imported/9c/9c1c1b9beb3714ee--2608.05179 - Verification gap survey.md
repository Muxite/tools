# 2608.05179 · Autonomous Research Agents: A Survey of AI Scientists and the Verification Gap

Ding, Nannapaneni, Liu, Zhang · arXiv 29 Jun 2026 (cs.CY) · 119 pp (77 body)
Read: abstract, §1-4 (p4-14), verification ladder (§9, p42-48), gap analysis (§11, p58), safety (§12), checklist and threats (§14-16, p68-69)

## Summary
⭐ The most useful single paper for the general report. It organises the field around
**verification rather than capability**: "It is no longer whether an agent can complete
a research task but whether we can trust the result, and whether anyone can check it
at all" (p4). Its unit of analysis is the **audit artifact a reviewer can inspect**
(code, seeds, traces, selection policy, novelty-check method, human entry points), not
the system's domain or autonomy label (p5).

## Method
- PRISMA-style search, 2023 to June 2026: 144 records → 125 → 35 included → **26 full-text
  coded** (24 runnable systems + 2 study/position works) on 7 audit dimensions (p8-9)
- Autonomy levels coded on 5 axes (initiative, judgment, execution, iteration,
  accountability): L0 assistive … L3 pipeline, L4 closed-loop split into **L4-m
  mechanical** (re-run on an internal metric) and **L4-v validated** (hypothesis revised
  against an outside oracle) (p10)
- Second-coder reliability: 90% on artifact release, only 50% autonomy, 60% novelty,
  60% selection; and the second pass was abstract-only (p9, p68)

## Findings (Table 4, p12)
| Disclosure (N = 24) | Rate |
|---|---|
| Releases code | 83% (20/24) |
| Releases prompts | 71% |
| Releases seeds or execution traces | **38%** (9/24) |
| Discloses result-selection policy | 67% |
| ≥1 human-in-the-loop point | 88% |
| Reports any novelty-verification method | **38%** |

- Of 9 L4 systems: 7 mechanical, 1 author-claimed without external check, 1 externally
  validated, and that one (CAMEO, Kusne et al. 2020) **predates LLM agents** (p10)
- "we found no system that reports independent validation that its novelty check is
  itself reliable" (p58)
- An LLM reviewer is now as common as benchmarking, 62% (p74)
- Historical contrast (p7): Robot Scientist/Adam/Eve and AutoML coupled search with
  checking; FunSearch, AlphaTensor, AlphaEvolve, Eureka and formal provers succeed
  "precisely when a verifier, not the model's own judgment, decides what counts".
  "The capability transferred; the verification did not"
- ChemCrow's authors report GPT-4 as its own evaluator "could not reliably separate
  correct from flawed outcomes" (p7)

## The verification ladder (Fig. 3, §9, p42-48)
I sound formal verifier · II executable test on held-out data · III simulator or physical
oracle · IV citation grounding · V learned verifier / proxy reward · VI human expert ·
VII weak inter-agent or infrastructural signal · VIII the model's own judgment.
A system is placed per output, not with one grade: a theorem prover is Tier I for the
proof but Tier V or VIII for the autoformalisation that chose the statement (p48).

## Gap analysis (Table 9, p58)
| Failure mode | Hiding proxy | Minimum evidence |
|---|---|---|
| Hallucinated citation (documented) | fluent prose | resolvable bibliography |
| Novelty overclaim (documented) | idea rating | novelty method |
| Weak baseline (documented) | headline metric | baseline source |
| Unreproducible run (documented) | single score | seeds, traces |
| Result selection (risk) | best-of-n | attempts, policy |
| Hidden labour (risk) | "autonomous" | per-stage HITL |
| Dual use (risk) | task focus | safety review |

## Reporting checklist (Table 10, p68)
Measured: HITL points, code, seeds/traces, novelty method, attempts and selection
policy. Proposed: baseline provenance, **reviewer independence (evaluator ≠
generator)**, **preregistered hypotheses**.

## Open problems (p69)
Proxy-to-truth validation for closed loops; closed-loop verifiers; novelty auditing at
literature scale; independent agent review; contamination-resistant evaluation;
**preregistration for AI-generated hypotheses**. Closing line: an AI scientist that
writes a manuscript "should be read as automating the production of research artifacts,
not yet providing the independent verification that would make its scientific claims
trustworthy".

## Limitations (stated)
Coding subjectivity (above); snapshot to mid-2026; centred on AI/ML research; many
entries are preprints (p68-69).
