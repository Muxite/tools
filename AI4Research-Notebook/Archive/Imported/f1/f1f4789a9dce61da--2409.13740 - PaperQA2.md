# 2409.13740 · Language Agents Achieve Superhuman Synthesis of Scientific Knowledge (PaperQA2)

Skarlinski, Cox, Laurent, Braza, Hinks, Hammerling, Ponnapati, Rodriques, White · FutureHouse, Rochester, Crick · v2 26 Sep 2024 · 25 pp (8 body)
Read: body p1-8 in full

## Summary
PaperQA2 is an agentic RAG system for the scientific literature. The paper builds a
human-comparison methodology on 3 real tasks, **retrieval QA, cited summarisation, and
contradiction detection**, and shows expert-level or better performance. It underpins
later FutureHouse/Edison systems (Robin's Crow and Falcon; Kosmos's literature agent).

## How it works (p3)
- RAG decomposed into tools the agent can call repeatedly: **Paper Search** (keyword
  queries), **Gather Evidence** (dense top-k → **LLM re-rank and contextual
  summarisation, RCS**, which scores each chunk's relevance and injects citation count
  and journal), **Citation Traversal** (citers and citees as hierarchical index),
  **Generate Answer** from top summaries
- Grobid parsing; ~14.5 papers parsed per question

## Results
- **LitQA2** (248 expert-written multiple-choice questions answerable only from a paper's
  body; "insufficient information" allowed): **precision 85.2%, accuracy 66.0%**,
  abstains 21.9% vs PhD-level humans at 73.8% precision, 67.7% accuracy with a week and
  full internet (p3). Superhuman precision (p = 0.0036), accuracy not different
- ⭐ **A non-agentic version with a hard-coded sequence had significantly lower accuracy**
  (p = 0.015), attributed to the agent revising searches (p3)
- RCS matters, but only above a "comprehension threshold": small models used for RCS
  *reduced* accuracy (p5)
- **WikiCrow** (240 gene articles, $4.48 each): "cited and unsupported" 13.5% vs
  Wikipedia 24.9%; uncited 3.5% vs 13.6%; precision 86.1% vs 71.2%; fewer reasoning
  errors (12 vs 26), similar attribution errors (p5-6)
- **ContraCrow**: claims extracted per paper by LLM calls (~35 per paper), each checked
  against the literature on an 11-point Likert scale. On the ContraDetect benchmark AUC
  0.842; at threshold 8: accuracy 73%, precision 88%, FPR 7%; picks "no evidence" for
  98% of 42 never-studied claims. On 93 biology papers: 6.85% of 3,180 claims flagged,
  **2.34 ± 1.99 contradictions per paper**, **70%** agreed by experts (F1 0.82) (p7)

## Limitations
- Biology-heavy; LitQA2 built by the same group that designed the system (they checked
  generalisation on 101 new questions, p3)
- The Wikipedia comparison is against human-written articles, not expert reviews

## Relevance
- REPORT.md §3.5: the reference **LLM claim-extraction + verification-against-literature**
  pipeline, with measured precision; the opposite end from AI4Research's regex extraction
- Abstention ("insufficient information", "no evidence") is built in and measured, the
  same honesty AI4Research gets from `insufficient` / `inconclusive` verdicts
- ⭐ Counterweight to Robin (2505.13400): here a fixed action sequence **lost** accuracy.
  For retrieval, adaptivity pays; the freeze argument is stronger for execution and
  grading than for search. Worth stating in §3.2 so the report is fair
