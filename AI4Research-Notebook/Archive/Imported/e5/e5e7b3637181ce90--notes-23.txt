SAY: Nothing in the library is ever edited or deleted: admitting, versioning, specializing and retiring each add a record. Sprint 3 froze on version 1.0. Version 1.1 arrives while it runs, so sprint 3 keeps 1.0 and sprint 4 uses 1.1. A new version must pass everything the old one passed, so it can't get worse on anything already tested. A narrower use becomes a specialization with its own id, and a changed contract is a new capsule. Retiring unloads the plugin and keeps the record, so a sprint that pinned that version can still resolve it. Every admitted capsule's tests are re-run on a schedule, so one that breaks later is caught and retired.
