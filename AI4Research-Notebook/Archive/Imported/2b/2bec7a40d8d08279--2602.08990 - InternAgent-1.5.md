# 2602.08990 · InternAgent-1.5: A Unified Agentic Framework for Long-Horizon Autonomous Scientific Discovery

InternScience Team, Shanghai AI Laboratory · arXiv 9 Feb 2026 · 64 pp (29 body)
Read: p1-16 (overview, architecture, deep research, experiment optimisation, memory). Results sections only skimmed; do not cite scores. Code: github.com/InternScience/InternAgent

## Summary
A general framework for autonomous discovery across **algorithm discovery** (formal /
computational) and **empirical discovery** (observations to generalisations, incl.
wet lab). Organised as 3 subsystems, **Generation, Verification, Evolution**, each
driven by a foundational capability: deep research, solution refinement, long-horizon
memory (p4-7). Reports leading results on GAIA, HLE, GPQA, FrontierScience and SGI-bench.

## How it works
- **Generation / deep research** (§2.2): a heterogeneous **cross-disciplinary knowledge
  graph** (documents, concepts, methods, datasets, settings, problems; typed edges) built
  by schema-guided extraction; retrieval merges graph paths with dense vectors into
  "path-structured evidence chains"
- **Flow Graph** (§2.2.2, p9): the research process is an explicit **DAG** G = (V, E);
  node v = (type ∈ {search, solve, answer}, content, state, knowledge context); edges
  typed "requires result from", "provides evidence for", "constrains reasoning of".
  **Built incrementally by a planner** from a root query; executable nodes activate
  when dependencies are satisfied and propagate context downstream
- Multi-path answers: direct, search-augmented and self-driven, then aggregated (p10)
- **Verification / solution refinement** (§2.3): **Graph-Augmented Monte Carlo Search**
  over a solution graph with 4 expansion operators: primary expansion, intra-branch
  evolution, cross-branch reference, multi-branch aggregation. Scores come from running
  code on benchmarks, from simulators, or from physical lab devices coordinated by the
  **Science Context Protocol (SCP)**, and are backpropagated (p10-11)
- **Evolution / Structured Cognitive Memory** (§2.4): procedural, episodic and semantic
  memory producing priors for later cycles

## Results (abstract level only this session)
- "leading performance" on GAIA, HLE, GPQA, FrontierScience; climate downscaling RMSE
  0.8488; reproduction of biological target identification (per abstract / search
  summary). Not verified against tables here

## Relevance
- ⭐ Closest research-agent analogue to AI4Research's **task DAG**: typed nodes, typed
  edges, dependency-driven activation. The difference is that the DAG is **grown by a
  planner during execution**, where AI4Research compiles and freezes it first
  (REPORT.md §3.3)
- Its "Verification subsystem" is optimisation against a metric, i.e. Tier II/III signal
  feeding search, which the verification-gap survey would code as L4-mechanical unless an
  outside oracle revises the hypothesis
- SCP is a lab-facing tool protocol, adjacent to MCP; worth a footnote if the report
  discusses lab integration
