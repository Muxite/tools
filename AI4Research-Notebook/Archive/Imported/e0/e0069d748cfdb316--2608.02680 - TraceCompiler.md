# 2608.02680 · TraceCompiler: Skill-Guided Mining and Compilation of LLM Agent Traces into Mostly Deterministic Workflows

arXiv Aug 2026 · 17 pp (13 body)
Read: p1, p3-11 fully (method, compiler skill, setup, both case studies, corpus denoising,
dependency-recovery tables, ablations, AppWorld cross-check)

## Summary
The inverse of intent compilation: instead of compiling a *stated* intent into a plan, it
mines clusters of noisy agent traces and compiles the **recurring intent** into an
executable, mostly deterministic workflow W = (V, E, B, G, I, O) with typed nodes, guards
and parameter bindings. The discipline is the interesting part: an inter-tool edge is
admitted **only when some argument of the consumer holds a value only the producer could
have produced**, with every alternative origin excluded; anything weaker is downgraded to
*suspected* and imposes no ordering constraint. Every hard edge carries an auditable tuple
⟨consumer, arg_path, value, producer, exclusions⟩.

## How it works (p3-5)
- Intent discovery: conversations embedded (request weighted double, rounds interleaved with
  canonicalised tool calls), threshold agglomeration at min intra-cluster similarity 0.45,
  support floor 5; under-merging preferred to over-merging (p3, p5)
- Denoising labels each action ESSENTIAL / RECOVERY / EXPLORATORY / REDUNDANT / DEAD_OUTPUT /
  POLICY_REQUIRED / UNKNOWN — nothing is silently dropped. Retry-vs-structure is resolved by
  **argument comparison**, never call counts: jittering args = retry; systematically distinct
  args = genuine fan-out; a counter advancing with constant query = a loop (p3)
- Bindings typed CONSTANT / USER_INPUT / COPY_EDGE / TRANSFORM_EDGE / **LLM_OR_DYNAMIC** —
  only the last justifies a runtime LLM node. Auth care: account credentials may be
  CONSTANT, but a bearer token is a session artifact and is always a COPY_EDGE (p4)
- A HUMAN node is emitted in exactly one circumstance — an irreversible external effect with
  an unresolvable binding (p3). Neither case study emits one, and the paper flags that rather
  than let the type list imply coverage
- The compiler is a versioned **skill** (instruction package) a frontier agent loads, not a
  trained model (p4)

## Results (p6-11)
- Dependency recovery on T1's training split, **15,775** deduplicated def-use edges over
  3,350 dialogues (Table p9): argument-level rule **0.928 precision / 0.943 recall / 0.936
  F1**; adjacency 0.584 / 0.908 / 0.711; all-pairs 0.231 precision; frequency-thresholded
  directly-follows 0.617 / 0.842 / 0.712. Wilson 95% CIs given per row
- Compiler skill run **blind** over five pre-chosen clusters: 248/250 = **0.992**
  [0.971, 0.998] on 48 dialogues — 1.6% of the corpus's edges (p9)
- AppWorld cross-check by deterministic replay: 563 token edges, 546 recovered, 4 FP, 17 FN →
  precision **0.993** [0.981, 0.997], recall 0.970 (p11)
- Corpus-wide removability over all 56 AppWorld scenarios (14,128 calls): **median removable
  fraction 51.4%** (IQR 41.9-74.1%, range 12.1-99.3%); 51/56 exceed 30%, 33/56 exceed 50% (p6)
- Case 1 (Venmo money request): 3 instances, 34 observed API calls → **11 runtime calls**
  (3, 3, 5), residual LLM nodes = 1 (the recipient-resolution branch). Under leave-one-out
  execution against AppWorld's own state tests it passes **15 of 21**; the failing fold
  escalates rather than acting, because the needed branch was never observed (1/7) (p6-7)
- Case 2 (Spotify/Todoist): 106 calls across 3 instances; the compiler **refuses to emit an
  executable graph** because whether each song is added to or removed from the playlist is
  under-determined and the two are opposite irreversible effects (p6-7)

## Limitations
The paper is unusually adversarial about itself; most of these are its own admissions.
- ⚠ Only the **training split** of T1 is used (25% of dialogues, the quarter with least
  structural diversity); the 40-template test split is untouched (p5)
- ⚠ Wilson intervals treat template-nested edges as independent Bernoulli trials, so they are
  **narrower than a template-clustered resampling would give** (p5)
- ⚠ The ablation is devastating to a naive reading of 0.928: choosing at **random** among the
  same surviving candidates drops precision to **0.403**, and choosing the earliest to 0.146
  (p10). Most of the accuracy is the most-recent-survivor heuristic, on a corpus where
  detection is trivial and exclusion is close to free
- ⚠ The 0.993 AppWorld figure is a **self-consistency check** — replay injects the tokens by
  a related heuristic — and an earlier draft's inference that 0.993 ≈ 0.992 shows
  corpus-independence is explicitly withdrawn (p11)
- ⚠ The released activity tables for the Venmo cluster are **incomplete** (30 of 34 calls
  enumerated) and the recoverable counts disagree with each other (11 vs 13); the authors
  flag it as a pending correction (p5 footnote)
- ⚠ The "frozen after five adversarial audit passes" claim is **testimony, not a checkable
  property**: the v1.0.0 text carried no version field and no audit log, and one post-freeze
  commit touched a helper script (p4)
- No offline compilation cost is measured, so **no net efficiency result is claimed** (p1, p3)
- Router accuracy is not evaluated, and the router gates a workflow whose terminal step moves
  money (p4)
- The 51.4% removability is not a realised saving — calls a compiled workflow need not issue,
  not measured end-to-end cost (p6)

## Relevance
- REPORT.md §3.1-3.3: the closest published work to **compiling intent into a typed,
  effect-aware DAG from evidence** rather than from a prompt — cross-reference Agint
  (2511.19635) and PlanCompiler (2604.13092), which start from stated intent
- Strongest pro-freeze evidence in this slice, and it is about **refusal**: the compiler
  declines to emit a graph for the under-determined irreversible mutation, and the
  leave-one-out fold that lacks its branch escalates instead of guessing (p7). A frozen plan
  that can abstain is safer than a loop that always produces something
- Its binding taxonomy (CONSTANT / USER_INPUT / COPY_EDGE / TRANSFORM_EDGE / LLM_OR_DYNAMIC)
  is directly reusable as the type system for AI4Research's frozen contract — it names
  exactly where model non-determinism is permitted to remain
- The self-critique of its own freeze claim (p4) is a cautionary note the report should
  quote: an unversioned, unlogged freeze is an assertion, not an integrity property
