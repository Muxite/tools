# DeepSeek Harness

[English](README.md) | Chinese

DeepSeek Harness (`dsh`) is an open-source agent harness developed by [DeepSeek AI](https://deepseek.com).

It is built on an architecture in which **everything is a plugin**, driven by [Cordis](https://github.com/cordiverse/cordis); see the paper [_A Programming Paradigm for Spatiotemporal Composability_](https://arxiv.org/abs/2608.25512) for its design.

Documentation: [https://deepseek-harness.github.io/deepseek-harness/](https://deepseek-harness.github.io/deepseek-harness/)

## Developer Preview

DeepSeek Harness is in the _developer preview_ stage and is iterating rapidly. **Breaking changes will occur in the future.**

Before running this project, please read the [safety notes](SAFETY.zh.md).

<a id="run"></a>

## Run

### Run via `npm`

Install `Node.js`, then run:

```sh
npx @deepseek-ai/dsh web
```

By default, this command starts the Web UI at `http://127.0.0.1:3080`; when started locally, it also opens the page with the default browser. When started via SSH, it only prints the host URL, because the local forwarding address is held by the SSH client or editor. You can pass `--no-open` to run only the server without opening the browser. See the [Web UI guide](docs/user/guide/index.zh.md) for details.

<a id="run-from-source"></a>

### Run from Source

To run from the repository source:

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

`pnpm run build` prepares the repository's build artifacts. `pnpm dsh web` directly uses these already-built artifacts; it does not rebuild them.
